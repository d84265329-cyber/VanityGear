Vanity Gear - Fabric source project for Minecraft Java 1.21.11

This is SOURCE CODE, not a prebuilt/verified JAR. It has not yet been compiled in this environment.

Build on GitHub:
1. Upload the ENTIRE contents of this folder to the ROOT of your GitHub repository.
2. Ensure .github/workflows/build.yml is included (GitHub may hide .github in some mobile file pickers).
3. Open Actions and run/inspect "Build Fabric mod".
4. If successful, open the completed run and download the "vanity-gear-build" artifact.
5. Unzip the artifact to get the JAR.

The workflow uses Java 21 and Gradle 8.14. A successful build is not yet a guarantee that Aternos supports uploading this custom JAR.
